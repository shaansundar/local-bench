# Benchmark catalog

Generated by `bench catalog` from each `benchmarks/<slug>/benchmark.yaml` — edit those, not this file.

Runner: **chat** = direct API call · **oc** = opencode agent in a sandboxed workspace · **native** = official harness.
Badges: **adapted** = harness differs from the official one · **substitute** = stand-in for an unavailable benchmark · **partial** = some subsets not run · **judge** = graded (partly) by the cloud judge.

- *PPTC (PowerPoint Task Completion)* — Runs the official PPTC modules in their own venv (python-pptx 0.6.21). The official harness truncates prompts to the GPT-4 limit (8,191 tokens); the same limit is used here.
